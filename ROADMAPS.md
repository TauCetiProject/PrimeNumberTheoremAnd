# PNT+ migration into Tau Ceti

Audit: 2026-11-13. Source: [PNT+ `938912b`](https://github.com/AlexKontorovich/PrimeNumberTheoremAnd/tree/938912bbff637bdb18025f0cfd62db3939b63b0a); library: [Tau Ceti `be86813`](https://github.com/TauCetiProject/TauCeti/tree/be86813dc92e6bac8614c2c2dd34572145df09c0); approved specifications: [TauCetiRoadmap `7342e8f`](https://github.com/TauCetiProject/TauCetiRoadmap/tree/7342e8fdd). The dependency's actual pins are in [lake-manifest.json](lake-manifest.json).

This is a migration inventory, not a claim that the refactor or upstream migration is complete. The source inventory contains 233 Lean files: 75 local `Mathlib/` extensions, 26 top-level files, one `Backlund/` file, 126 `IEANTN/` files, four `Unused/` files and one tactic file. Counts describe the inherited source tree; they will fall as duplicates are removed. `README.md`'s upstream notice redirects new IEANTN work to [teorth/IEANTN](https://github.com/teorth/IEANTN); the inherited IEANTN mathematics remains part of this fork's audit.

For complete migration, genuinely additional specifications are still needed for:

- **Kernel-checked finite certifications:** numerical zero verification, prime-gap/Goldbach tables and rational enclosure certificates, with precise source data, coverage and endpoint guarantees. ZerosOfLFunctions [layer 9](https://github.com/TauCetiProject/TauCetiRoadmap/blob/7342e8fdd/TauCetiRoadmap/ZerosOfLFunctions/README.md#layer-9-certified-zeros) specifies certificate semantics and explicitly computes no zeros. The explicit proposals generally take finite verification as hypotheses. Existing `native_decide` proofs and `TrustedNumerics` admissions cannot enter Tau Ceti unchanged; proving a conditional theorem does not migrate the missing verification.
- **Finite Goldbach transfer and computation:** `IEANTN/Goldbach` includes binary checks and explicit ternary ranges. [CircleMethodThreePrimes #1803](https://github.com/TauCetiProject/TauCetiRoadmap/pull/1803) explicitly excludes binary Goldbach, Helfgott's theorem and all numerical thresholds; it does not cover these finite claims.
- **Erdős problem 392's factorial factorization optimization:** `IEANTN/Erdos392` constructs balanced factorizations and proves asymptotic bounds on the number of factors bounded by `n` or `n²`. Existing logarithmic-factorial/PNT targets supply inputs, not this optimization theorem. A narrow new target must specify both headline conclusions and the balance/score prerequisites.

## Migration discipline and current queue

`Unused/` contains alternative Fejér, Hardy–Tauberian, zeta-bound and Montgomery–Vaughan developments; audit their actual consumers before retaining mathematical APIs. Source-only discarded experiments need no replacement library. Any independently retained theorem still needs an exact approved target or prerequisite argument. `HoffsteinLockhart` also contains blueprint prose, which is not a proved theorem. The tactic simproc and external certificate tooling belong to human-owned tooling, not `TauCeti/` mathematics.

Before opening each independent upstream PR, check current main and related work. At this audit, [#38972](https://github.com/TauCetiProject/TauCeti/pull/38972) covers order-one Hadamard, [#36738](https://github.com/TauCetiProject/TauCeti/pull/36738) finite-order zero counting, [#37557](https://github.com/TauCetiProject/TauCeti/pull/37557) primitive Dirichlet growth, and [#39175](https://github.com/TauCetiProject/TauCeti/pull/39175) Mathlib Wiener–Ikehara reuse. These are pending work, not available dependency APIs. Wait for prerequisites to merge, then update the fork's pin, remove replaced code and rebuild every affected consumer. Preserve attribution, use canonical mathematical carriers, and satisfy Tau Ceti's source, axiom, linter and PR-roadmap requirements. Update this report after each migration batch or roadmap merge.
