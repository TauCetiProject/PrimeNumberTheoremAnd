# PNT+ migration into Tau Ceti

Updated 2026-11-13. Dependencies: [Tau Ceti `da52798`](https://github.com/TauCetiProject/TauCeti/tree/da527980caecf7e72838e069c01f4a7e7633eca3), [Mathlib `e8ba86f`](https://github.com/leanprover-community/mathlib4/tree/e8ba86fa9744dd8d90f48c1752bc735f61a4ca81), stock Lean `v4.36.0-rc2`; exact pins are in [lake-manifest.json](lake-manifest.json). Approved specifications were checked against [TauCetiRoadmap `45f58db`](https://github.com/TauCetiProject/TauCetiRoadmap/tree/45f58dbecae1651c045f8ab24464aa3fecdd51b9).

The retained fork has **88 library modules, one example and 36,754 lines of Lean**, including comments and blanks. At the user's request, IEANTN's 126-module tree, its dedicated Backlund/Fourier/Euler-bound support and LeanCert/PrimeCert dependencies are excluded. Its separate project is [teorth/IEANTN](https://github.com/teorth/IEANTN). This was a scope deletion, not a duplication or proof claim.

The original source-by-source reuse pass covered every retained module. The forward dependency pass additionally compared 291 Mathlib API headers and all 11 newly added Mathlib files, and adopted the new `WeakPNT` endpoints. The subsequent Tau Ceti batch changed 403 files; its 17 selected relevant modules and all changes in the retained import closure were checked. Native half-line asymptotic bounds now simplify Laplace boundedness, and native Hurwitz growth at parameter zero replaces the completed-zeta order-one proof and compact-bound wrapper, removing another 273 lines. These are bounded audits at the recorded revisions; upstream migration and adoption of newly merged APIs continue.

## Verification and retained distinctions

Current source passes the complete library build, blueprint indexing and rectangle example. All **3,282 compiled library declarations** pass the standard-axiom and declaration-ownership audit; there are no remaining admissions. The full complex Ramanujan, alternate ζ³ and Liouville identities are proved. [The forward dependency update](https://github.com/TauCetiProject/PrimeNumberTheoremAnd/commit/dfbd92a7fa0ad2c28f6cbcc2b05f19fb6f397e9c) also passes GitHub CI; the subsequent [WeakPNT adoption](https://github.com/TauCetiProject/PrimeNumberTheoremAnd/commit/88c889477b094e54ea4775cfbfd89c14a52791fe) passes GitHub CI too.

Native finite-order APIs replace local nonnegative-order work; the local negative-order convention remains distinct (native `OrderLE` admits constant 2, the local predicate excludes it). Weak residue/product statements lack meromorphic hypotheses and remain. StrongPNT already uses native local factorization, while its flexible-radius estimate allows radii excluded by the native bound. W21 retains C²/integrable-derivative hypotheses; Schwartz/C∞ density is not an exact replacement. Unique proved `Unused/` results are retained. `HoffsteinLockhart` is blueprint prose, and the simproc belongs to human-owned tooling rather than Tau Ceti mathematics.
